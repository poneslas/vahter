# UX оверлея: опыт, состояния, визуальный язык

17.10.2026 · уточняет ТЗ, раздел 7. Макеты: `design/Макеты_оверлея.html`. Инструменты и их жизненный цикл: `Локальные_инструменты.md`. Звук, распознавание и эквалайзер: `Голосовой_контур.md`.

## 1. Принципы опыта

1. **Нажал — уже слушаю.** Оверлей открывается сразу в режиме «Слушаю». Пре-ролл 0,5 с ловит слово, сказанное одновременно с нажатием.
2. **Видно, кто работает.** Два цвета на весь продукт: **янтарный — телефон**, **синий — Hermes**. Цвет носят эквалайзер, значок у реплики и полоса карточки. Цветом не кодируем ничего другого.
3. **Одна плашка на всё** (урок Гига Писаря). Слушание, ответ, карточки и ошибки — это состояния одного листа снизу, а не всплывающие окна поверх него.
4. **Ничего не происходит молча.** Любое действие на телефоне оставляет строку в разговоре с кнопкой «Отменить», даже если его выполнило правило за 50 мс.
5. **Голос и руки равноправны.** В любой момент можно перейти на клавиатуру. Голосовое «да» равно нажатию «Да».
6. **Hermes говорит коротко, подробности прячутся.** Служебные шаги Hermes сворачиваются в одну строку-гармошку. Озвучивается только первый абзац.
7. **Перебивать можно всегда.** Нажатие во время ответа сразу останавливает речь и снова слушает.

## 2. Анатомия оверлея

Лист снизу поверх любого приложения. Под ним приложение затемнено на 30 %.

```
┌───────────────────────────────┐
│          ───  (ручка)         │
│ ● Hermes · сессия 5 мин  [≡]  │  шапка: связь, сессия, «История»
│                               │
│  …последние реплики…          │  разговор текущей сессии
│  [карточки действий]          │
│                               │
│  Поставь будильник на семь    │  живая зона: моя речь (караоке)
│  со̶р̶о̶к̶                       │  или произносимый ответ
│                               │
│  [⌨]      ▂▅█▆▃▂▄       [✕]   │  панель: клавиатура · эквалайзер · закрыть
└───────────────────────────────┘
```

| Высота | Как попасть | Что видно |
|---|---|---|
| **Компактная**, ~45 % экрана | открытие по кнопке | живая зона и 1–2 последних обмена |
| **Развёрнутая**, ~90 % | свайп вверх по листу | вся текущая сессия, лента прокручивается |
| **История**, полный экран | кнопка «История» или свайп вверх из развёрнутой | весь канал за всё время, поиск |
| **Закрыто** | свайп вниз, «✕», нажатие на затемнение | — |

Эквалайзер — одновременно индикатор и главная кнопка: нажатие во время речи завершает фразу сразу, в покое — начинает слушать.

## 3. Голосовой цикл

```
      кнопка ассистента
             │
             ▼
   ┌──── Слушаю ◄─────────────────────────────────────────┐
   │   (ждём речь, 8 с)                                   │
   │         │ речь                                        │
   │         ▼                                             │
   │   Говорю  — эквалайзер живой, караоке                 │
   │         │ пауза 0,7 с / отпустил кнопку / нажал       │
   │         ▼                                             │
   │   Распознаю — волна, чистовик ≤ 0,5 с                 │
   │         │                                             │
   │         ├── локальная команда ─► Выполнено ──(5 с)────┤ слушаю продолжение
   │         │                                             │
   │         └── в Hermes ─► Hermes думает ─► Отвечает ────┘ после ответа 6 с
   │                            (волна синяя)  (речь + караоке)
   ▼
 тишина 8 с ─► Пауза: микрофон выключен, лист остаётся, «Нажмите, чтобы говорить»
                 │ 30 с без действий
                 ▼
               лист закрывается сам (если нет карточки, ждущей ответа)
```

| Событие | Реакция |
|---|---|
| Нажатие на эквалайзер, пока говорю | фраза закончена сейчас, без ожидания паузы |
| Удержание кнопки ассистента | режим рации: слушаю, пока держишь |
| Нажатие во время ответа Hermes | речь останавливается, ответ дописывается текстом, снова «Слушаю» |
| Свайп вниз во время работы Hermes | лист закрывается, ответ дойдёт в ленту и уведомлением |
| «Стоп», «отмена», «не надо» сразу после команды | отмена последнего действия, если оно обратимо |

**Окно продолжения.** После ответа микрофон слушает ещё 6 с без нажатия, как в голосовом режиме Claude. Так разговор идёт без кнопок. Окно отключается в настройках.

## 4. Как печатается сказанное

- **Караоке своей речи.** Первые слова появляются через 0,6–0,8 с речи. Зафиксированные слова рисуются основным цветом, нефиксированный хвост — на 45 % прозрачности. Чистовик заменяет черновик плавной сменой отдельных слов, строка не прыгает.
- **Крупно, пока говорю.** В живой зоне текст 22 sp. После отправки фраза уезжает вверх в разговор и становится обычной репликой 16 sp.
- **Исправить сказанное.** Нажатие на свою реплику → «Исправить» → поле с текстом и курсором. Отправка заменяет реплику и повторяет запрос. Для Hermes это новая реплика с пометкой «исправлено».
- **Пустое и тишина** — короткая строка в живой зоне, без диалогов: «Ничего не расслышал», «Микрофон отдаёт тишину — проверьте гарнитуру».

## 5. Ручной ввод

- Кнопка «⌨» превращает живую зону в поле ввода. Лист поднимается над клавиатурой, эквалайзер сжимается в маленькую кнопку микрофона внутри поля.
- Микрофон в поле запускает голос, и сказанное **дописывается в поле**, а не отправляется: так можно диктовать и править руками.
- «Отправить» идёт тем же путём, что и голос: правила → маршрутизатор → Hermes.
- Начал печатать — окно продолжения и озвучка ответа выключаются до конца сессии: если человек перешёл на клавиатуру, скорее всего, вокруг тихо.

## 6. Визуальный язык: кто что сделал

| Элемент | Вид | Когда |
|---|---|---|
| **Моя реплика** | справа, мягкая плашка, значок микрофона или клавиатуры | всегда |
| **Ответ Hermes** | слева, без плашки, синяя точка у первой строки | ответ сервера |
| **Ответ телефона** | слева, янтарная точка, одна строка | короткие ответы маршрутизатора: «Таймер на 5 минут» |
| **Строка действия** | янтарный значок, итог одной строкой, «Отменить», подпись источника: «на телефоне» | локальная команда выполнена, П0 |
| **Карточка подтверждения** | полоса сверху синяя, если просит Hermes, янтарная, если телефон; параметры; «Да / Изменить / Отмена» | П1 |
| **Карточка-черновик** | как подтверждение, но главная кнопка «Открыть в …» | П2: сообщения |
| **Гармошка «Hermes работает»** | одна строка с бегущим бликом: «Смотрю почту…»; после ответа — «4 шага · 6 с», раскрывается по нажатию | служебный вывод Hermes |
| **Карточка плана** | группы с объёмами и превью, «Применить / Изменить / Отмена», после — «Вернуть всё» | `files.plan` |
| **Вопрос-уточнение** | строка вопроса и быстрые варианты-кнопки | маршрутизатор или Hermes спрашивают |
| **В очереди** | пунктирный контур, «Передам Hermes, когда будет связь» | нет сети |
| **Ошибка** | строка с причиной и действием: «Нет доступа к календарю · Разрешить» | любой сбой |

После выполнения карточка подтверждения сворачивается в строку действия. Так разговор не превращается в стопку кнопок, а история сохраняет, что произошло.

**Подпись источника** у строки действия: «на телефоне» (правило или маршрутизатор) или «Hermes → телефон». Подробности, какое именно правило сработало, — только в журнале.

## 7. Голос ответа

**В первой версии ответ только текстом, синтеза речи нет.** Всё ниже — когда включим озвучку.

- Озвучивается первый абзац финального ответа Hermes. Остальное — текстом ниже, приглушённо.
- Произносимое слово подсвечено (караоке ответа по `onRangeStart`). Эквалайзер в это время синий и следует за голосом синтеза.
- Ответ стримится текстом раньше, чем начинается речь. Озвучка стартует с первого законченного предложения.
- Короткие ответы телефона («Таймер на 5 минут») звучат сразу, без задержки на сеть.

## 8. История

- Весь канал с Hermes одной лентой, свежее внизу.
- Разделители: день и начало сессии («Новая сессия · 14:20»).
- Гармошки Hermes и строки действий сохраняются в свёрнутом виде.
- Поиск по тексту, фильтр «Только действия».
- Нажатие на ответ — «Повторить голосом», «Копировать», «Поделиться».
- Из истории можно продолжить: поле ввода внизу работает так же, как в оверлее.

## 9. Экран блокировки

- Вопросы работают полностью: Hermes отвечает голосом и текстом.
- История и прошлые сессии скрыты, видна только текущая.
- Действия с данными (календарь, файлы, звонки, сообщения) показывают карточку «Разблокируйте, чтобы добавить». После разблокировки действие выполняется без повторной просьбы.
- Таймер, будильник, фонарик, громкость работают без разблокировки, это настраивается.

## 10. Звук и тактильность

| Момент | Звук | Вибрация |
|---|---|---|
| Начал слушать | короткий тон, тихий | лёгкий тик |
| Фраза закончилась | нет | нет |
| Действие выполнено на телефоне | нет | двойной тик |
| Нужна реакция (карточка П1) | мягкий тон | тик |
| Ошибка | нет | длинная вибрация |

Звуки выключаются отдельно от вибрации. В режиме «без звука» тоны не играют, но озвучка ответа работает, если громкость медиа не ноль.

## 11. Ошибки и пустые состояния

| Ситуация | Текст | Действие |
|---|---|---|
| Нет сети, вопрос для Hermes | «Нет связи с Hermes. Передам, когда появится» | «Отменить отправку» |
| Hermes не отвечает 20 с | «Hermes долго не отвечает» | «Подождать» / «Отменить» |
| Сервер несовместим после обновления | «Сервер обновился, канал не работает. Локальные команды доступны» | «Подробнее» |
| Нет разрешения | «Нет доступа к календарю» | «Разрешить» |
| Роль ассистента сброшена (при запуске приложения) | «Кнопка ассистента снова открывает Google» | «Вернуть» |
| Первая сессия, разговор пуст | подсказки-примеры: «Поставь таймер на 10 минут», «Что у меня завтра?», «Почисти загрузки» | нажатие отправляет пример |

Ошибки не извиняются и всегда говорят, что делать дальше.

## 12. Доступность

- Все кнопки ≥ 48 dp, подписаны для TalkBack. Эквалайзер объявляется как «Слушаю, нажмите, чтобы закончить».
- Текст масштабируется системной настройкой. Живая зона при крупном шрифте переносит строки, а не уменьшает текст.
- «Уменьшить движение»: эквалайзер становится одной полосой уровня, лист появляется без пружины, блик на гармошке не бежит.
- Цвет никогда не единственный носитель смысла: у источника всегда есть подпись или значок.

## 13. Словарь интерфейса

Одно действие — одно слово во всём продукте.

| Где | Слово |
|---|---|
| Состояния | Слушаю · Распознаю · Hermes думает · Hermes отвечает · Пауза |
| Кнопки карточек | Поставить / Добавить / Применить · Изменить · Отмена |
| После действия | Поставлено / Добавлено / Применено · Отменить |
| Отмена выполненного | Отменить → «Отменено» |
| Черновики | Открыть в Telegram / в Сообщениях |

## 14. Что проверяем на макетах и в Ф1

1. Хватает ли двух цветов, чтобы с первого взгляда понять, где выполняется действие.
2. Не мешает ли окно продолжения (6 с): не ловит ли посторонние разговоры.
3. Читается ли караоке на ходу: размер, прозрачность хвоста, скорость смены.
4. Понятна ли гармошка Hermes без подписи.
5. Сколько карточек помещается в компактную высоту, не закрывая живую зону.
