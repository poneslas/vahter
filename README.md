# Тася: голосовой ассистент для Android со сменным мозгом

**Экономия каждой секунды при обращении к ИИ-агенту.** Без запуска приложений, без набора текста, без проговаривания промптов: будильник, «что заказать» по фото меню, перевод, «что это?» — в пару нажатий, с ответом сразу. Тася заменяет системного помощника Android: распознавание речи на телефоне, никаких трекеров, модель на твой выбор.

Нажал кнопку — сразу говоришь с моделью. Речь распознаётся на телефоне (GigaAM), простые команды телефон выполняет сам, остальное отвечает **мозг**: DeepSeek напрямую по API (любой OpenAI-совместимый) или свой агент Hermes на сервере с памятью, поиском и Telegram. Мозг выбирается для каждого режима.

## Где мы сейчас

17.10.2026 · **проектирование закончено, кода нет. План: два мозга с общими абстракциями; реализуем DeepSeek, сразу следом Hermes** (`Бэклог.md`, журнал). Следующий шаг — пробник (`Проверки_на_устройстве.md`) и этап 0: репозиторий, сборка, интерфейс мозга с фейковой реализацией (`Архитектура.md`, разделы 2.2 и 17).

Нужно до этапа 1:
- **ключ DeepSeek** (platform.deepseek.com);
- **скриншоты голосового режима Claude** — для сверки макетов.

Сервер Hermes (где стоит, версия, домен) нужен к этапу 5 — сразу после DeepSeek.

Тестовый телефон — Samsung Galaxy S24 Ultra.

## Что читать

| `Продукт.md` | что делаем: принципы, сценарии, границы v1, опыт оверлея |
| `Архитектура.md` | как устроено: компоненты, голос, действия, контракт с мозгом, сервер, проверки; в приложениях — параметры голоса и формат инструментов |
| `Проверки_на_устройстве.md` | диагностическое приложение-пробник: 17 проверок платформы на телефоне (роль, лист, камера, файлы, разворачивание, ярлыки, пуш, обновление, распознавание), критерии и запасные варианты |
| `probe/` | код пробника (`ru.poneslas.tasya.probe`) — Android-проект для проверок из `Проверки_на_устройстве.md`; ведёт отдельная сессия |
| `Бэклог.md` | журнал решений, открытые вопросы, будущее развитие, гипотезы |
| `design/Прототип.html` | **кликабельный прототип**. Открывается «Знакомством» — 6 шагов, отмечаются сами. Вкладка «Сценарии» — по группам: каждый день, ответы мозга, первый запуск, сбои; у каждого своя ссылка (`#gastro`, `#nomic`…). «Мир» меняет сеть, сервер, модель, блокировку; «Журнал» объясняет, что происходит. Помнит последний сценарий |
| `design/prototype/` | код прототипа по слоям, как будущее приложение: `model.js` — модель данных (режимы, настройки, состояние), `ui.js` — экраны, `voice.js` — запись и жесты, `session.js` — лист, камера, вложения, `brain.js` — разговор (мозг здесь фейковый), `services.js` — модель речи и подключение, `actions.js` — действия пользователя; `harness.js` — обвязка демо, в Android не переносится |
| `design/Действия_v1.html` | путь вызова действия и пять классов отмены |
| `research/` | исследования, на которых держатся решения: референсы, стандарты, оценка Hermes |
