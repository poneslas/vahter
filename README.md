# Тася: голосовой ассистент для Android с серверным мозгом

**Экономия каждой секунды при обращении к ИИ-агенту.** Без запуска приложений, без набора текста, без проговаривания промптов: будильник, «что заказать» по фото меню, перевод, «что это?» — в пару нажатий, с ответом сразу. Тася заменяет системного помощника Android: распознавание речи на телефоне, никаких трекеров, свой агент и своя модель.

Нажал кнопку — сразу говоришь с собственным серверным агентом (сейчас Hermes). Речь распознаётся на телефоне (GigaAM), простые команды телефон выполняет сам, остальное делает мозг на сервере — у тебя на глазах.

Тестовый телефон — Samsung Galaxy S24 Ultra.

## Что читать

| Документ | О чём |
|---|---|
| `Продукт.md` | что делаем: принципы, сценарии, границы v1, опыт оверлея |
| `Архитектура.md` | как устроено: компоненты, голос, действия, контракт с мозгом, сервер, проверки; в приложениях — параметры голоса и формат инструментов |
| `Бэклог.md` | журнал решений, открытые вопросы, будущее развитие, гипотезы |
| `design/Прототип.html` | **кликабельный прототип**. Открывается «Знакомством» — 6 шагов, отмечаются сами. Вкладка «Сценарии» — по группам: каждый день, ответы мозга, первый запуск, сбои; у каждого своя ссылка (`#gastro`, `#nomic`…). «Мир» меняет сеть, сервер, модель, блокировку; «Журнал» объясняет, что происходит. Помнит последний сценарий |
| `design/Действия_v1.html` | путь вызова действия и пять классов отмены |
| `research/` | исследования, на которых держатся решения: референсы, стандарты, оценка Hermes |
