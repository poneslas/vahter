# Вахтёр: голосовой ассистент для Android со сменным мозгом

**Экономия каждой секунды при обращении к ИИ-агенту.** Без запуска приложений, без набора текста, без проговаривания промптов: будильник, «что заказать» по фото меню, перевод, «что это?» — в пару нажатий, с ответом сразу. Приложение заменяет системного помощника Android: распознавание речи на телефоне, никаких трекеров, модель на твой выбор.

Нажал боковую кнопку — сразу говоришь. Речь распознаётся на телефоне (GigaAM), простые команды телефон выполняет сам, остальное отвечает **мозг**: DeepSeek напрямую по API (любой OpenAI-совместимый) или свой агент Hermes на сервере с памятью, поиском и Telegram. Мозг выбирается для каждого режима.

## Где мы сейчас

21.10.2026 · **версия 0.8.1 — Hermes подключается: через его API-сервер, по ссылке-приглашению; поток, шаги, подтверждения команд, картинки и файлы от мозга.** Как устроено — `docs/Архитектура.md`, 9.0; сервер — `server/`.

Что есть в коде:
- лист поверх приложений: вкладки режимов, push-to-talk (зажать / вверх — без рук / влево — отмена), поле с клавиатурой, развернуть в приложение и обратно;
- голос — как в Гига Писаре для Android (MIT, перенесён в `app/…/pisar/`): GigaAM v3 с пунктуацией, модель одним файлом 225 МБ, кнопка записи — зажал и говоришь, вверх — замочек, к середине — отмена;
- DeepSeek: потоковый ответ, ошибки по-русски, ключ в Keystore с проверкой; 17 действий на телефоне — будильник (поставить, выключить, ближайший), таймер, календарь (смотреть, создавать), фонарик, громкость, «Не беспокоить», музыка, местоположение, места, заметки, открыть приложение или настройки, набрать номер, подготовить сообщение; у каждого — «Разрешено / Спрашивать / Не разрешено», доступы Android спрашиваются при первом разе, всё пишется в журнал;
- Hermes: подключение по ссылке-приглашению (или адрес и ключ телефона), выбор мозга у режима; ответ потоком, шаги инструментов сервера, карточка подтверждения опасной команды, картинки и файлы от мозга (папка `vahter-out`). Действий телефона у Hermes нет; история режима — на сервере;
- таймер и будильник без сети по точной фразе;
- фото: камера в листе на весь экран (обрезать, обвести, стрелка, несколько кадров одной репликой), галерея через системный выбор фото; фото-режимы открываются сразу камерой;
- свои режимы: промпт с диктовкой, подсказки, что принимают, главное действие;
- первый запуск: один мастер из семи шагов (Продукт 5.13) — приветствие, голос, боковая кнопка, проба голоса, две сцены про режимы, мозг; заканчивается в листе;
- заблокированный экран: по умолчанию сначала разблокировка; экран погас — лист закрывается и запись останавливается; ответ при закрытом листе приходит уведомлением.

Оформление сверяется с прототипом: `tools/compare/run.sh` снимает одинаковые экраны с прототипа и эмулятора и кладёт парами в `out/compare/index.html`.

Не проверено на S24: живой голос, камера, разблокировка из листа и скачивание моделей по сети — на эмуляторе этого не проверить. Список проверки — ниже.

Тестовый телефон — Samsung Galaxy S24 Ultra, One UI 9.5, Android 16.

## Сборка и установка

```
./gradlew :app:assembleDebug
adb install -r -g app/build/outputs/apk/debug/app-debug.apk
adb shell cmd role add-role-holder android.app.role.ASSISTANT ru.poneslas.vahter.dev
adb shell input keyevent KEYCODE_ASSIST        # открыть лист
```

Отладочная сборка ставится как отдельное приложение `ru.poneslas.vahter.dev` и подписана отладочным ключом.

Выпускная — `./gradlew :app:assembleRelease` → `app/build/outputs/apk/release/app-release.apk`, приложение `ru.poneslas.vahter`. Подпись берётся из `local.properties` (`vahter.release.*`, не в git); сам ключ — вне репозитория. Без ключа обновление выпускной сборки не подписать: держите резервную копию ключа и паролей.

### Проверка на S24 (≈10 минут)

1. Установить `out/vahter-0.7.7-dev.apk` и открыть «Вахтёр». Первый запуск проведёт по семи шагам; свайп вправо или «Назад» — шаг назад.
2. «Голос на телефоне»: «Скачать» (≈240 МБ) — качается, пока настраивается кнопка.
3. «Своих — без очереди»: выбрать «Вахтёр» цифровым помощником; вторая строка — что сейчас на удержании кнопки (на One UI должно сразу стать ✓).
4. «Попробуйте голосом»: пока голос качается — столбики-полоска со швом; потом зажать микрофон, сказать, отпустить — фраза крупно и «⚡ Распознано на телефоне за N с»; вверх к замку — без пальца, влево — отмена.
5. Две сцены про режимы — «Далее». «Подключите мозг» (последний): вставить ключ DeepSeek → «Подключить» → «DeepSeek подключён» → «Открыть» — откроется лист с «Вам чего?».
6. Зажать боковую кнопку: Ассистент сразу слушает (замочек закрыт). Сказать «поставь будильник на семь тридцать» и нажать «Отправить» — будильник появится в «Часах». Потом зажать микрофон в листе: отпустить — уйдёт; вверх — замочек; к середине — отмена.
7. Спросить что-нибудь длинное и закрыть лист — ответ придёт уведомлением.
8. Вкладка «Что это?» → камера → обвести что-нибудь → ↑. Затем 📎 → «Галерея».
9. Заблокировать телефон и зажать кнопку — сначала попросит разблокировать, потом откроет лист.
10. Во время записи погасить экран — лист должен закрыться.
11. Действия: «включи фонарик», «выключи будильник на 7:30», «что у меня завтра в календаре», «сделай потише», «включи не беспокоить», «открой Telegram», «напиши маме в WhatsApp, что задержусь». В строке итога — что сделано и кнопка «Отменить», где можно. SDK — `~/Dev/.toolchains/android-sdk` (`local.properties`), JDK 21.

## Языки

Все тексты интерфейса — в `app/src/main/res/values/strings.xml` (русский — исходный). Новый язык: скопировать файл в `values-xx/strings.xml` (например `values-en`) и перевести; числа — через `<plurals>`. В коде строка берётся `tr(R.string.ключ)`, множественное число — `trp(R.plurals.ключ, n)`. Не переведены пока: слова локальных команд («таймер», «фонарик» — `actions/PhoneActions.kt`) и описания функций для мозга (`actions/PhoneTools.kt`). Ключи — по смыслу: `<область>_<суть>` (`ui_yes`, `wiz_brain_title`, `set_voice_dl`); общие слова — `ui_*`. Новые строки заводятся руками сразу в `strings.xml`; `tools/i18n/extract.py` — только для разовой выгребки зашитых в код русских строк (ключи после него переименовать).

## Прототип

`docs/design/Прототип.html` открывается в браузере. Сначала первый запуск — тот же мастер из семи шагов, что в приложении. Вкладка «Сценарии» — по группам, у каждого своя ссылка (`#gastro`, `#nomic`…). «Мир» меняет сеть, ключ, блокировку, доступы; «Журнал» объясняет, что происходит.

Код прототипа разложен по тем же границам, что приложение (таблица соответствия — Архитектура, раздел 14): `core.js` — состояние и мир, `model.js` — модель данных, `ui.js` — экраны и лист, `onboarding.js` — шаги мастера, `intro.js` + `intro.css` — сцены мастера, `voice.js` — запись и жесты, `session.js` — лист, камера, вложения, `brain.js` — разговор (мозг фейковый), `services.js` — модель речи и подключение, `actions.js` — действия пользователя (`data-act`); `harness.js` — обвязка демо, в Android не переносится. Страницы и шаги называются так же, как в приложении.
