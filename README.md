# Тася: голосовой ассистент для Android со сменным мозгом

**Экономия каждой секунды при обращении к ИИ-агенту.** Без запуска приложений, без набора текста, без проговаривания промптов: будильник, «что заказать» по фото меню, перевод, «что это?» — в пару нажатий, с ответом сразу. Приложение заменяет системного помощника Android: распознавание речи на телефоне, никаких трекеров, модель на твой выбор.

Нажал боковую кнопку — сразу говоришь. Речь распознаётся на телефоне (GigaAM), простые команды телефон выполняет сам, остальное отвечает **мозг**: DeepSeek напрямую по API (любой OpenAI-совместимый) или свой агент Hermes на сервере с памятью, поиском и Telegram. Мозг выбирается для каждого режима.

## Где мы сейчас

19.10.2026 · **версия 0.2.0 — оформление по прототипу, голос как в Гига Писаре для Android.** Следующий этап — Hermes (`docs/Архитектура.md`, раздел 17).

Что есть в коде:
- лист поверх приложений: вкладки режимов, push-to-talk (зажать / вверх — без рук / влево — отмена), поле с клавиатурой, развернуть в приложение и обратно;
- голос — как в Гига Писаре для Android (MIT, перенесён в `app/…/pisar/`): GigaAM v3 с пунктуацией, модель одним файлом 225 МБ, кнопка записи — зажал и говоришь, вверх — замочек, к середине — отмена;
- DeepSeek: потоковый ответ, ошибки по-русски, ключ в Keystore с проверкой; 17 действий на телефоне — будильник (поставить, выключить, ближайший), таймер, календарь (смотреть, создавать), фонарик, громкость, «Не беспокоить», музыка, местоположение, места, заметки, открыть приложение или настройки, набрать номер, подготовить сообщение; у каждого — «Разрешено / Спрашивать / Не разрешено», доступы Android спрашиваются при первом разе, всё пишется в журнал;
- Hermes — пока страница «скоро» с описанием, что он будет уметь;
- таймер и будильник без сети по точной фразе;
- фото: камера в листе на весь экран (обрезать, обвести, стрелка, несколько кадров одной репликой), галерея через системный выбор фото; фото-режимы открываются сразу камерой;
- свои режимы: промпт с диктовкой, подсказки, что принимают, главное действие;
- первый запуск: помощник и боковая кнопка, скачивание голоса, ключ, уведомления;
- заблокированный экран: по умолчанию сначала разблокировка; экран погас — лист закрывается и запись останавливается; ответ при закрытом листе приходит уведомлением.

Оформление сверяется с прототипом: `tools/compare/run.sh` снимает одинаковые экраны с прототипа и эмулятора и кладёт парами в `out/compare/index.html`.

Не проверено на S24: живой голос, камера, разблокировка из листа и скачивание моделей по сети — на эмуляторе этого не проверить. Список проверки — ниже.

Тестовый телефон — Samsung Galaxy S24 Ultra, One UI 9.5, Android 16.

## Сборка и установка

```
./gradlew :app:assembleDebug
adb install -r -g app/build/outputs/apk/debug/app-debug.apk
adb shell cmd role add-role-holder android.app.role.ASSISTANT ru.poneslas.tasya.dev
adb shell input keyevent KEYCODE_ASSIST        # открыть лист
```

Отладочная сборка ставится как отдельное приложение `ru.poneslas.tasya.dev` и подписана отладочным ключом (релизный ключ — после проверки).

### Проверка на S24 (≈10 минут)

1. Установить `out/tasya-0.4.0-dev.apk` и открыть «Тася». Первый запуск проведёт по шагам.
2. «Боковая кнопка»: выбрать «Тася» цифровым помощником, удержание кнопки — помощник.
3. «Голос»: скачать (225 МБ), в конце — «Попробуйте здесь»: зажать микрофон, сказать, отпустить.
4. «Мозг»: вставить ключ DeepSeek → «Проверить».
5. Зажать боковую кнопку: Ассистент сразу слушает (замочек закрыт). Сказать «поставь будильник на семь тридцать» и нажать «Отправить» — будильник появится в «Часах». Потом зажать микрофон в листе: отпустить — уйдёт; вверх — замочек; к середине — отмена.
6. Спросить что-нибудь длинное и закрыть лист — ответ придёт уведомлением.
7. Вкладка «Что это?» → камера → обвести что-нибудь → ↑. Затем 📎 → «Галерея».
8. Заблокировать телефон и зажать кнопку — сначала попросит разблокировать, потом откроет лист.
9. Во время записи погасить экран — лист должен закрыться.
10. Действия: «включи фонарик», «выключи будильник на 7:30», «что у меня завтра в календаре», «сделай потише», «включи не беспокоить», «открой Telegram», «напиши маме в WhatsApp, что задержусь». В строке итога — что сделано и кнопка «Отменить», где можно. SDK — `~/Dev/.toolchains/android-sdk` (`local.properties`), JDK 21.

## Языки

Все тексты интерфейса — в `app/src/main/res/values/strings.xml` (русский — исходный). Новый язык: скопировать файл в `values-xx/strings.xml` (например `values-en`) и перевести; числа — через `<plurals>`. В коде строка берётся `tr(R.string.ключ)`, множественное число — `trp(R.plurals.ключ, n)`. Не переведены пока: слова локальных команд («таймер», «фонарик» — `actions/PhoneActions.kt`) и описания функций для мозга (`actions/PhoneTools.kt`). Новые русские строки из кода переносит `tools/i18n/extract.py`.

## Прототип

`docs/design/Прототип.html` открывается в браузере. Сначала «Знакомство» — 6 шагов, отмечаются сами. Вкладка «Сценарии» — по группам, у каждого своя ссылка (`#gastro`, `#nomic`…). «Мир» меняет сеть, ключ, блокировку, доступы; «Журнал» объясняет, что происходит.

Код прототипа разложен как будущее приложение: `model.js` — модель данных, `ui.js` — экраны, `voice.js` — запись и жесты, `session.js` — лист, камера, вложения, `brain.js` — разговор (мозг фейковый), `services.js` — модель речи и подключение, `actions.js` — действия пользователя; `harness.js` — обвязка демо, в Android не переносится.
