# Тасечкин: голосовой ассистент для Android с серверным мозгом

Нажал кнопку — сразу говоришь с собственным серверным агентом (сейчас Hermes). Речь распознаётся на телефоне (GigaAM), простые команды телефон выполняет сам, остальное делает мозг на сервере — у тебя на глазах.

## Где мы сейчас

17.10.2026 · **проектирование закончено, кода нет.** Следующий шаг — этап 0 (репозиторий, сборка, фейковый мозг, контракт) и спайки: короткие проверки рискованных допущений (`Архитектура.md`, разделы 17–18).

Нужно до этапа 1 (`Бэклог.md`, раздел 2):
- **сервер:** где стоит Hermes, какая версия, есть ли домен;
- **рабочее название приложения;**
- **скриншоты голосового режима Claude** — для сверки макетов.

Тестовый телефон — Samsung Galaxy S24 Ultra.

## Что читать

| Документ | О чём |
|---|---|
| `Продукт.md` | что делаем: принципы, сценарии, границы v1, опыт оверлея |
| `Архитектура.md` | как устроено: компоненты, голос, действия, контракт с мозгом, сервер, проверки; в приложениях — параметры голоса и формат инструментов |
| `Бэклог.md` | журнал решений, открытые вопросы, будущее развитие, гипотезы |
| `design/Прототип.html` | **кликабельный прототип**: первый запуск, загрузка модели, подключение, обычный день; панель «мир» меняет сеть, сервер, модель, блокировку |
| `design/Макеты_оверлея.html` | живой оверлей и раскадровки (открыть в браузере) |
| `design/Действия_v1.html` | путь вызова действия и пять классов отмены |
| `research/` | исследования, на которых держатся решения: референсы, стандарты, оценка Hermes |
