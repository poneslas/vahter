## Что не сработало и почему — коротко

- **Окна поверх листа.** Всё, что запускается из листа через `startAssistantActivity` (разрешения, выбор файла и фото), на S24 оказывается под листом. Решение: разрешения — из приложения; выбор — «сначала спрятать лист».
- **Микрофон не выключается сам**, когда лист скрыт; держать запущенным нельзя — горит индикатор. Решение: создать заранее, запускать в `onPrepareToShowSession`, останавливать в `onHide`.
- **Замеры при зависшем Mac** завысили время в 2–4 раза. Перед замерами на эмуляторе — убедиться, что Mac не занят (headless-браузеры, сборки).
- **httpbin** обрывает медленные потоки — для проверок фона нужен свой или надёжный сервис.
- **Разблокировка из `onCreate`** отменяется системой; запрос — после получения окном фокуса, с одним повтором.
- **Чужой микрофон в клавиатурах.** Samsung Keyboard и Gboard не берут стороннюю голосовую клавиатуру ни при каких настройках. Голосовой метод ввода (`imeSubtypeMode="voice"`) не показывается в списке выбора клавиатуры, даже с включённым подтипом, — только `keyboard`.
- **Документы считали S24 на Android 17** — на самом деле Android 16 / One UI 9.5.

Полные отчёты пробника (`report.json`) в репозиторий не клали; их содержание сведено в `../Проверки_на_устройстве.md`, раздел 9.
