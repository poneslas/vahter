# Варианты будущего развития

17.10.2026 · всё, что не вошло в `Архитектура_v1.md`. Это не обещания и не план. У каждого пункта есть причина, почему его нет в v1, и условие, при котором к нему стоит вернуться.

Архитектура v1 оставляет для каждого пункта точку расширения: сменный интерфейс, место в контракте или отдельный модуль. Возврат к пункту не должен требовать переделки ядра.

## Ближайшее: v1.1 — когда v1 используется каждый день

| Что | Почему не в v1 | Когда вернуться | Точка расширения в v1 |
|---|---|---|---|
| **Нейросетевой маршрутизатор** (классификатор + парсеры, ~15 команд, класс «не моё») | правил хватает для первых команд; нужен датасет из реальных фраз | журнал покажет частые фразы, которые правила упускают | интерфейс `Router` |
| **Озвучка ответа** с караоке; выбор голоса на слух из 3–4 вариантов | текстом достаточно, синтез — отдельная большая тема | захочется пользоваться без взгляда на экран: в машине, на кухне | интерфейс `SpeechSynthesizer` |
| **Режим `steer`**: дополнение без прерывания текущего хода | штатное прерывание с учётом новых вводных закрывает основной случай, как в Telegram | прерывания начнут ломать длинные задачи | настройка плагина |
| **«Что на экране»**: скриншот и структура экрана в мозг по «да» | приватность и объём работы | понадобится «переведи это», «что это за место» | инструмент `screen.read` в реестре |
| **Отправить мозгу одно фото** (камера или галерея) | загрузка, ошибки, прогресс | простые вопросы по фото станут частыми | вложения в `turn` |
| **Уведомления**: «что пришло важного?», «отправь в Hermes» | спецдоступ, хранение, правила | захочется сводку без открытия мессенджеров | `NotificationListenerService` + инструменты |
| **Файлы за секунды**: «почисти загрузки», «найди файл» через план | SAF, корзина, план | загрузки начнут мешать | вид карточки «План», `files.*` |
| **Экран всей истории** с поиском и фильтром «только действия» | искать проще вопросом мозгу | понадобится смотреть журнал действий глазами | журнал уже ведётся |

## Средний горизонт: доработки мозга и каналов

| Что | Суть | Когда вернуться |
|---|---|---|
| **Архив артефактов** | плагин Hermes копирует файлы из всех каналов до суточной очистки кэша, ведёт индекс; агент ищет и пересылает; в приложении — экран «Файлы». Подробно — `Открытые_вопросы.md`, В20 | ценные файлы начнут теряться |
| **Telegram-представитель** | отдельный профиль Hermes в чужих группах: роль, наблюдение, регулярные сводки. Подробно — `Открытые_вопросы.md`, В5 | появится конкретная группа, за которой надо следить |
| **Второй мозг и шлюз** | наш сервис с драйверами (ACP, Claude Agent SDK); приложение не меняется. Подробно — `Мозг_и_шлюз.md` | Hermes не проходит пороги из `Мозг_и_шлюз.md`, раздел 7 |
| **Прогресс серверной задачи в уведомлении** | «Hermes работает: 3 шага» обновляется пушами | долгие исследования станут нормой |
| **Сквозная сессия с Telegram** | продолжить в оверлее разговор, начатый в Telegram, и наоборот. Сейчас у Hermes сессии раздельные по каналам, общие только память и поиск | раздельность начнёт мешать |

## Гипотезы: даже не план

Записаны, чтобы не потерялись. Возвращаться только при новом понимании или новых возможностях платформы.

| Гипотеза | Почему нет |
|---|---|
| **Долгие фоновые задачи на телефоне** («рассортируй фото за лето») | оверлей — окно, а не процесс; нужен foreground-сервис, прогресс, возврат результата вне разговора, ограничения Android 14+. Для этого есть галереи и файловые менеджеры, с ними не конкурируем |
| **Телефон как сопроцессор мозга** (сканирование, разметка, дубликаты со сводкой) | имеет смысл только вместе с долгими задачами |
| **Полноценный локальный агент** (малая LLM через LiteRT-LM, многошаговые задачи офлайн) | превращает ассистента в отдельный продукт; референс — `LiteRtLmOpenAiProxy.kt` в adybag14 |
| **Модель «речь в речь» как голос спереди** (OpenAI Realtime, Gemini Live), передающая сложное мозгу | звук уходит в облако, дорого, качество на русском не подтверждено, два мозга с раздельной памятью. Встаёт драйвером в шлюз |
| **Длинная диктовка на серверной GigaAM** | на телефоне хватает для коротких фраз; сервер Писаря (`giga-pisar-cli`, OpenAI-совместимый `/v1/audio/transcriptions`) — готовая основа |
| **Wake word** («Эй, …») | батарея и ложные срабатывания; если понадобится — KWS из sherpa-onnx, не Vosk |
| **Фоновый голосовой режим с выключенным экраном** | foreground-сервис с микрофоном; для коротких задач не нужен |
| **Управление чужими приложениями через спецвозможности** | ломается с обновлениями приложений, даёт полный контроль над телефоном |
