# Открытые вопросы

Живой список. Сюда попадают вопросы, которые меняют архитектуру или опыт пользователя. Отвечаем по мере возможности. Когда вопрос закрыт, решение переносится в ТЗ или профильный документ, а здесь остаётся строка со ссылкой.

Статусы:
- **открыт** — думаем;
- **есть предложение** — нужен ответ пользователя;
- **меряем** — решение по замеру в указанной фазе;
- **закрыт** — решение принято.

Обновлено 17.10.2026, вечер.

**Границы проекта** (решено 17.10): на телефоне только короткие действия, пока открыт разговор; долгие фоновые задачи, сопроцессор и локальный агент — гипотезы, не план (ТЗ, раздел 17); ни с кем не конкурируем; синтеза речи в первой версии нет.

## История: предложение по В8 и В14

**Наблюдение.** С агентом проще переспросить, чем листать историю. Значит, история — не главный экран, а запасной.

1. **Главный путь — спросить голосом.** «Что ты мне вчера говорил про сырники?» Мозг ищет в своей истории сам: у Hermes есть полнотекстовый поиск по сессиям, у Claude Code — компакция и память. Отдельного интерфейса для этого не нужно, только навык «ищи в прошлых разговорах, прежде чем переспрашивать».
2. **Текущая сессия — в самом оверлее.** Свайп вверх разворачивает лист до 90 % экрана. Это не «оверлей в оверлее», а та же плашка выше.
3. **Вся история — обычный экран приложения**, а не ещё один слой поверх чужого приложения. Открывается кнопкой из оверлея; оверлей при этом закрывается. Поиск, разделители сессий, фильтр «Только действия».
4. **Переслать любой ответ — системным «Поделиться».** Долгое нажатие на ответ → меню Android → Telegram, WhatsApp, заметки. Это главное преимущество бота, и его можно получить без дублирования переписки.
5. **Зеркалить в Telegram-бот не будем по умолчанию.** Два места с одной перепиской путают и удваивают поверхность для утечек. Если понадобится — отдельная настройка «копировать ответы в Telegram» на стороне мозга: Hermes умеет слать в несколько платформ.

Макеты: `design/Макеты_оверлея.html`, раздел «Развёрнутый лист и история».

## Представитель: предложение по В5

- Отдельный профиль Hermes (`hermes profile`) со своим Telegram-ботом, памятью и ролью в `SOUL.md`.
- В группах: в BotFather выключить privacy mode или сделать бота админом; в конфиге `require_mention: true`, `observe_unmentioned_group_messages: true` и список разрешённых чатов. Бот читает всё, отвечает только на упоминание.
- Регулярная сводка — cron в этом профиле, доставка тебе: в личку Telegram, позже в приложение.
- Безопасность: чужие сообщения — недоверенный ввод. У представителя минимум инструментов, нет доступа к основной памяти и телефону, связь с основным мозгом только в одну сторону (он шлёт сводки, команд из чужих чатов не принимает).
- Ограничения Telegram: бот виден как бот, добавить его может только админ, сообщений других ботов и истории до своего прихода он не видит.

Источник: `upstream/hermes-agent/website/docs/user-guide/messaging/telegram.md`, разделы «Privacy Mode» и «Observe group chatter without auto-replying»; `user-guide/profiles.md`, `multi-profile-gateways.md`.

## Артефакты: предложение по В20

**Что есть в Hermes (проверено по исходникам, HEAD 83597d9b71).**
- Отдельного реестра артефактов нет. В таблице `messages` хранится только текст; путь к файлу остаётся, только если он был в тексте ответа.
- Входящие файлы (из Telegram и других каналов) и исходящие (графики, PDF, таблицы, озвучка) лежат в `~/.hermes/cache/{images,documents,audio,videos,screenshots}`.
- Шлюз раз в час удаляет всё старше **24 часов** (`gateway/run.py`, `_housekeeping_media_caches`, `max_age_hours=24`).
- Сейчас долгосрочный архив по факту — облако Telegram, и то только для того, что шло через Telegram.

**Предложение: свой архив артефактов.** Отдельный небольшой плагин Hermes, не связанный с приложением.
- **Входящие:** хук `pre_gateway_dispatch` видит каждое входящее сообщение из любого канала с путями к скачанным файлам. Плагин копирует их в `~/.hermes/artifacts/` до очистки кэша.
- **Исходящие:** хуки `transform_llm_output` / `post_llm_call` дают текст ответа; плагин вынимает из него пути так же, как это делает Deliverable Mode. `post_tool_call` ловит файлы от `image_generate`, `text_to_speech` и других инструментов.
- **Индекс** в SQLite: канал, сессия, направление (от меня / от агента), имя, тип, размер, время, подпись и соседний текст сообщения, хеш против дублей.
- **Инструмент для агента** `artifacts.search` / `artifacts.send`: «найди тот PDF с договором и пришли» работает в любом канале, в том числе в Telegram.
- **В приложении — экран «Файлы»:** сетка и список, фильтры по типу, направлению и каналу; открыть, поделиться, сохранить на телефон. В оверлее файл в ответе — плашка с превью, по нажатию открывается.
- **Агностичность:** архив живёт на нашей стороне. При смене мозга он переезжает в шлюз (`Мозг_и_шлюз.md`), формат индекса тот же.

**Что решить:**
- срок хранения и квота (например, без срока для документов, 90 дней для голосовых);
- шифрование архива на диске сервера;
- что не архивировать: голосовые сообщения, скриншоты экрана телефона, файлы из чужих групп представителя.
