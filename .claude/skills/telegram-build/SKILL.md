# Отправка в Telegram

Каждую новую сборку для пользователя — отправить ему в Telegram, вложением, с описанием.

1. Собрать выпускную: `./gradlew :app:assembleRelease`, скопировать в `out/vahter-<версия>.apk`. Отладочная (`-dev`) в лимит ботов 50 МБ не влезает — отправлять выпускную.
2. Написать заметки во временный файл (scratchpad), по-русски, коротко, без кухни (канон текстов — Продукт 5.12):
   ```
   Вахтёр <версия>

   Что нового:
   • …

   Проверить на телефоне:
   • … (то, что не проверено на эмуляторе: голос, кнопка, камера, уведомления, карточки действий…)
   ```
3. Отправить: `python3 tools/release/send_telegram.py out/vahter-<версия>.apk <заметки>` (с выключенной песочницей — нужна сеть).
4. Сказать пользователю, что сборка отправлена, и повторить в ответе главное из заметок.

Токен бота и id чата владельца — только в `../.toolchains/keys/telegram-builds.env` рядом с папкой проекта (вне репозитория). Не выводить их на экран и не класть в git.
Ошибка «chat not found» — владелец ещё не нажал /start у бота (@VillageTelegraph_bot): попросить нажать.
