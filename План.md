# План: голосовой ассистент для Android с ядром на Hermes

28.09.2026 · коротко. Подробности — в `Расширенный_план.md`, общая картина — в `Презентация_архитектуры.html`.

## Логика этапов

Сначала **тонкий сквозной прототип**. Он проверяет пять самых рискованных узлов на реальном телефоне, по одной функции на узел. Только когда он работает, начинаем наращивать функции. Каждая фаза заканчивается проверкой в жизни.

## Фазы

| Фаза | Что получаем | Проверка |
|---|---|---|
| **0. Подготовка** | среда сборки, тестовый телефон, сервер с Hermes, домен и Caddy, макеты оверлея | макеты утверждены, пустое приложение ставится на телефон |
| **1. Сквозной прототип** | оверлей по кнопке с караоке и эквалайзером · GigaAM на телефоне · плагин `android` в Hermes, потоковый ответ текстом · Hermes ставит будильник через карточку · 3 локальные команды без сети | все пять узлов работают на твоём телефоне, сценарий демо проходит целиком |
| **2. Надёжный канал** | лента и история, привязка устройства по коду и ключу, реконнект и офлайн-очередь, новая сессия после паузы, полная дизайн-система | неделя пользования вместо Telegram-бота Hermes |
| **3. Локальный мозг** | нейросетевой маршрутизатор (классификатор + параметры), ~15 локальных команд, заметки с копией в память Hermes | 90% бытовых команд выполняются без сервера |
| **4. Телефон для Hermes** | набор функций `phone.*`, карточки подтверждений и уточнений Hermes, «что на экране», черновики сообщений; манифест возможностей на ходу | «добавь встречу из письма в календарь» работает |
| **5. Уведомления** | сбор выбранных приложений, сводка, «отправь в Hermes», правила пересылки | «что важного пришло?» даёт полезный ответ |
| **6. Файлы** | доступ к папкам, корзина, `scan` → `plan` → `apply` за секунды, «почисти загрузки» | загрузки чистые, всё можно вернуть |

Фазы 5–6 можно переставлять. Озвучка ответа — опция после Ф1: сначала ответ только текстом.

## Границы проекта

- На телефоне — только короткие действия, пока открыт разговор. Долгие фоновые задачи, сопроцессор и локальный агент — гипотезы, не план (ТЗ, раздел 17).
- Ни с кем не конкурируем: файлы, видео и длинные разборы — в Telegram, сортировка фото — в галерее.
- Синтез речи в первой версии не делаем.

## Пять рискованных узлов прототипа

1. **Оверлей.** `VoiceInteractionSession` на Compose открывается за 300 мс, работает поверх любого приложения и экрана блокировки, показывает караоке и эквалайзер.
2. **Локальное распознавание.** GigaAM v3 int8 через sherpa-onnx: фраза 5 с распознаётся за 0,5 с, черновик текста бежит во время речи.
3. **Связь с сервером.** Плагин `android` на стоковом Hermes, WSS через Caddy, потоковый ответ текстом.
4. **Команда от сервера.** Hermes вызывает `phone.set_alarm`, телефон показывает карточку и ставит будильник после «да».
5. **Локальное выполнение.** Таймер, будильник и фонарик по простым правилам работают в режиме полёта.

## Что нужно от тебя до старта

- модель тестового телефона и версия Android;
- сервер для Hermes: где он, какая версия Hermes, есть ли домен;
- скриншоты голосового режима Claude и того, что открывается по долгому нажатию питания;
- рабочее название приложения.
